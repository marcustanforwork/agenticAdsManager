# `@ads/contracts`

**Job:** Zod schemas, types and pure helpers shared by every package: money (bigint micros), canonical JSON and hashing, settings, packs, outcomes, platform clients, write actions and their undo table, findings, proposals and operator requests (BLUEPRINT §3).

**May depend on:** `zod` only.

The rules are BLUEPRINT §2, enforced by `pnpm check:boundaries` (see `scripts/boundary-rules.mjs`).
